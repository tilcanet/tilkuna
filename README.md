# IKU – TILKUNA

> **"El vuelo de la curiosidad que nos guía la historia y la cultura de Tilcara"**  
> *"Aprendé, Jugá, Descubrí, Tilcara"*

Proyecto Educativo y Tecnológico desarrollado por los estudiantes de **4.° Año, 3.ª División** de la **Escuela Normal Superior "Dr. Eduardo Casanova"** de Tilcara, Jujuy.

🏆 **Clasificado a la Instancia Nacional de la Feria de Arte, Ciencias y Tecnología 2026**  
🏛️ **Declarado de Interés Cultural, Educativo y Turístico Municipal** por el Concejo Deliberante de Tilcara (Minuta de Declaración N° 023/2026-HCDT).

---

## 📖 Descripción del Proyecto

El proyecto **IKU – TILKUNA** aborda la problemática del desconocimiento del patrimonio cultural, histórico y natural de Tilcara mediante el enfoque pedagógico **STEAM** (Ciencia, Tecnología, Ingeniería, Artes Visuales y Matemática) y el **Aprendizaje Basado en Proyectos (ABP)**.

El proyecto nació originalmente como una maqueta física dotada de un circuito eléctrico interactivo (con luces LED verde para acierto y roja para error) que conecta **12 sitios emblemáticos** de la localidad. En esta etapa de digitalización, se desarrolló una plataforma web multijugador interactiva en tiempo real construida con **Node.js, Express, WebSockets, HTML5, CSS3 y JavaScript**, proyectada para su sincronización con hardware Arduino mediante Web Serial API.

## 🚀 Instalación y Puesta en Marcha Local

### Requisitos previos
* [Node.js](https://nodejs.org/) (versión 18 o superior recomendada)
* Git

### Pasos
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/TU-USUARIO/tilkuna.git
   cd tilkuna
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Iniciar el servidor:
   ```bash
   npm start
   ```

4. Abrir en el navegador:
   ```
   http://localhost:3000
   ```
